# Fluent Path

目的別に英語学習メニューを作る静的Webアプリです。

## Features

- 初回診断テスト
- 目的別カリキュラム
- Speaking / Writing / Reading / Listening の4技能課題
- XP、連続学習日数、レベル表示
- 各ユーザーのブラウザ内 `localStorage` に進捗保存

## Local Preview

```bash
python3 -m http.server 4173
```

Open:

```text
http://127.0.0.1:4173/
```

## Deploy

This app is fully static. Deploy these files to any static hosting service:

- `index.html`
- `styles.css`
- `app.js`

Recommended options:

- GitHub Pages
- Netlify
- Vercel
- Cloudflare Pages
